How to use it in the exam
  1. Read the question, find its key phrase in the Index (“derive the inverse kinematics”, “mobility”…).
  2. Go to the Recipe, follow the steps, then the week page for the formulas and a worked example.
  3. Forgotten a derivation? The Derivations section has each key result line by line.
