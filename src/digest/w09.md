# W09 — Control (Part 2) (50 pages; keys w09-lec, w09-prac)

Deck covers: partitioned (computed-torque) control for non-linear SISO systems, MIMO manipulator, imprecise model, Cartesian-space control, force control, hybrid force/position. It does **not** contain: Lyapunov stability, impedance/admittance control, any numeric worked example, or the gain-selection (critical damping) rule (that was Week 8 and is only referred to as "like being critically damped", p. 8). Format throughout: lecture slides with a few handwritten annotations. ## Formulas
(All "source: slide image" = rendered and read unless stated.)

1. Linear plant (p. 8): $m\ddot x + b\dot x + kx = f$ ; m mass [kg], b damping [N·s/m], k stiffness [N/m], f control force [N], x position [m]. Source: slide text/image.
2. Non-linear spring (p. 9): $f_{spring}=kx^3$; $m\ddot x + b\dot x + kx^3 = f$ (second-order, non-linear, constant coefficients). Slide image has handwritten "= αf′ + β" next to f.
3. Partitioned law (p. 10): $f=\alpha \acute f+\beta$, with $\alpha=m$, $\beta=b\dot x+kx^3$. Servo law: $\acute f=\ddot x_d + k_v\dot E + k_p E$, $E=x_d-x$. α scales (mass), β cancels the non-linear/other terms; f′ (written f with acute accent) is the commanded acceleration. Source: slide image.
4. Single link, friction (pp. 12–13): $\tau_v=b_v\dot q$ (viscous), $\tau_c=b_c\,\mathrm{sgn}(\dot q)$ (Coulomb). EoM: $\tau = mL^2\ddot q + b_v\dot q + b_c\,\mathrm{sgn}(\dot q) + mgL\cos q$. L link length [m], m point mass at the tip, q angle from the horizontal, g gravity. Handwritten derivation on p. 13: $\mathcal L=K-P$; $Q=\frac{d}{dt}\left(\frac{\partial\mathcal L}{\partial\dot q}\right)-\frac{\partial\mathcal L}{\partial q}$; $K=\tfrac12 m(\dot x^2+\dot y^2)$; $P=mgy=mgL\sin q$; $x=L\cos q$, $y=L\sin q$, $\dot y=L\cos q\,\dot q$. Source: slide image.
5. Control law for single link (p. 14): $\tau=\alpha\acute\tau+\beta$, $\alpha=mL^2$, $\beta=b_v\dot q+b_c\,\mathrm{sgn}(\dot q)+mgL\cos q$, $\acute\tau=\ddot q_d+k_v\dot E+k_pE$. Handwritten label "Dynamics equation of motion" on the EoM. Source: slide image.
6. MIMO partition (p. 18): $F=\alpha\acute F+\beta$, dimensions F n×1, α n×n, F′ n×1, β n×1. Servo: $\acute F=\ddot X_d+K_v\dot E+K_pE$ (K_v, K_p n×n; Ẽ, E n×1). Notes: α chosen to decouple the n equations; α is **not** diagonal; K_v, K_p usually diagonal. Source: slide image.
7. Manipulator dynamics (p. 19): $\mathbf Q=\mathbf M(\mathbf q)\ddot{\mathbf q}+\mathbf C(\mathbf q,\dot{\mathbf q})+\mathbf g(\mathbf q)+\mathbf f(\dot{\mathbf q})$, each n×1 except M n×n. Computed torque: $\mathbf Q=\boldsymbol\alpha\acute{\mathbf Q}+\boldsymbol\beta$, $\boldsymbol\alpha=\mathbf M(\mathbf q)$, $\boldsymbol\beta=\mathbf C(\mathbf q,\dot{\mathbf q})+\mathbf g(\mathbf q)+\mathbf f(\dot{\mathbf q})$, servo $\acute{\mathbf Q}=\ddot{\mathbf q}_d+\mathbf K_v\dot{\mathbf E}+\mathbf K_p\mathbf E$. Block diagram p. 20: red box (M(q) and the C+g+f feedback) "linearises the system"; green box (K_p, K_v, error loops) "stabilises the closed-loop system". Source: slide image.
8. Closed loop, perfect model (p. 21): $\ddot{\mathbf E}+\mathbf K_v\dot{\mathbf E}+\mathbf K_p\mathbf E=\mathbf 0$; with diagonal gains, per joint $\ddot e+k_{vi}\dot e+k_{pi}e=0$ (linear and decoupled). Source: slide image.
9. Imprecise model (p. 27): hats = estimates. $\mathbf Q=\boldsymbol\alpha\acute{\mathbf Q}+\boldsymbol\beta$, $\boldsymbol\alpha=\hat{\mathbf M}(\mathbf q)$, $\boldsymbol\beta=\hat{\mathbf C}(\mathbf q,\dot{\mathbf q})+\hat{\mathbf g}(\mathbf q)+\hat{\mathbf f}(\mathbf q,\dot{\mathbf q})$, same servo law. Note: the true dynamics on p. 27 are written with f(q̇) while β̂ has f̂(q, q̇).
10. Closed loop with imprecise model (p. 28): $\ddot{\mathbf E}+\mathbf K_v\dot{\mathbf E}+\mathbf K_p\mathbf E=\hat{\mathbf M}^{-1}(\mathbf q)\big[(\mathbf M-\hat{\mathbf M})\ddot{\mathbf q}+(\mathbf C-\hat{\mathbf C})+(\mathbf g-\hat{\mathbf g})+(\mathbf f-\hat{\mathbf f})\big]$ (arguments as on slide). So the right-hand side is non-zero: modelling error acts as a forcing term on the error dynamics. I checked this symbolically from items 7, 9 (agrees). Source: slide image.
11. Cartesian trajectory generation (p. 31): $\mathbf q=\mathcal K^{-1}(\mathbf x)$; $\dot{\mathbf q}=J^{-1}(\mathbf q)\dot{\mathbf x}$; $\ddot{\mathbf q}=\dot J^{-1}(\mathbf q)\dot{\mathbf x}+J^{-1}(\mathbf q)\ddot{\mathbf x}$. 𝒦 = forward kinematics map, J = Jacobian. Slide: "All these are computationally intensive." Source: slide image.
12. Cartesian dynamics (p. 32): $\mathcal F=\mathbf M_x(\mathbf q)\ddot{\mathbf x}+\mathbf C_x(\mathbf q,\dot{\mathbf q})+\mathbf g_x(\mathbf q)$; joint torques $\mathbf Q=\mathbf J^\top(\mathbf q)\mathcal F$. 𝓕 = Cartesian force/wrench. Control: p. 33 block diagram: servo (K_p, K_v on x_d − x, ẋ_d − ẋ, with ẍ_d feed-forward) → M_x(q) → + (c_x + g_x) → 𝓕 → Jᵀ(q) → manipulator; x from 𝒦(q), ẋ from J(q)q̇ (feedback). Source: slide image.
13. Force-control plant (pp. 36–37): mass m pushing on a wall modelled as spring $f_e=k_e x\Leftrightarrow x=k_e^{-1}f_e$. Handwritten: $f-f_e-f_{dist}=m\ddot x$. $f=m\ddot x+f_{disturb}+f_e=mk_e^{-1}\ddot f_e+f_{disturb}+f_e$. Partition: $\alpha=mk_e^{-1}$, $\beta=f_{disturb}+f_e$. Law: $f=mk_e^{-1}\big[\ddot f_d+k_v\dot E+k_pE\big]+f_{disturb}+f_e$, $f_d$ desired interaction force, $E=f_d-f_e$. Closed loop $\ddot E+k_v\dot E+k_pE=0$ (p. 38; written bold K there).
14. Disturbance problem (p. 38): law contains f_disturb, which is not known, so it is **infeasible**.
15. Option 1 (p. 39): drop f_disturb: $f=mk_e^{-1}[\ddot f_d+k_v\dot E+k_pE]+f_e$ ⇒ $\ddot E+k_v\dot E+k_pE=f_{disturb}/(mk_e^{-1})$; steady-state error $E=\dfrac{f_{disturb}}{mk_e^{-1}k_p}$.
16. Option 2 (p. 39): use f_d in place of (f_disturb + f_e): $f=mk_e^{-1}[\ddot f_d+k_v\dot E+k_pE]+f_d$ ⇒ $\ddot E+K_v\dot E+\left(1/(mk_e^{-1})+k_p\right)E=f_{disturb}/(mk_e^{-1})$; steady-state $E=\dfrac{f_{disturb}}{1+mk_e^{-1}k_p}$. (I re-derived both steady-state errors from the stated closed loops; they agree.)
17. Comparison (p. 40): for a stiff environment (k_e large) the Option 2 (Case 2) steady-state error is smaller than Case 1.
18. Block diagrams (pp. 41–43): p. 41 full law with f̈_d, ḟ_d = d/dt(f_d) and d/dt(f_e) feedback; p. 42 same with f̈_d, ḟ_d crossed out as 0 and the d/dt(f_e) block flagged "Not a good idea" (differentiating a noisy force measurement); p. 43 practical form: $f=m\big[k_e^{-1}k_pE-k_v\dot x\big]+f_d$ with E = f_d − f_e, using velocity ẋ feedback instead of Ė, gain k_p/k_e in the outer loop.
19. Stiffness unknown (p. 44): k_e usually chosen as a high value; controller designed to be robust to small changes in k_e.
20. Hybrid control (p. 47): diagram: position control law (inputs ẍ_d, ẋ_d, x_d; feedback x) → S; force control law (input 𝓕_d; feedback 𝓕_E) → S'; outputs summed to 𝓕 → Cartesian arm; "Constraints" feed S and S'. S, S' diagonal with 0 or 1 entries, **complementary** (S' = I − S implied by "complementary"; not written), indicating whether each degree of freedom is in force or position mode. Slide says "joint"; the diagram is in Cartesian space (Craig style).

"Consider the 3-link planar manipulator shown below.
The geometry of the robot is given as L1 = 3m, L2 = 2m, L3 = 1m. The robot starts from rest where the end effector pose is given as (5,1,90o). We would like to move it to (-3,3, 180o) and come to a rest there.
In week 6, you learnt how to determine the trajectory. Say you are using a cubic interpolation between joint angles.
a. Compute the trajectory of each joint and plot it.
In week 8, you learnt how to compute the joint torques at each point in the trajectory. This is the inverse dynamics problem. The masses are given as m1 = 3kg, m2 = 2kg, m3 = 1kg. Assume that they are concentrated at the distal ends of each link.
b. Use the Lagrangian formulation to obtain an equation of motion of the following form.
 Q = M(q) q̈ + C(q, q̇) + g(q) + f(q, q̇)
Now, let us try to develop a controller for the robot. For the sake of simplicity, consider the first link at the first instance of time. Ignore friction.
c. In the initial configuration, compute the matrices M, c and g.
d. The desired position qd is known. At each timestep, it is the next position that the joint must move to.
e. Write down a partitioned control law for the joint torque.
f. Give this torque as input to the system (i.e., write a program that takes torque as input, follows the system dynamics, and gives joint positions and velocities as outputs. In other words, write a forward dynamics simulator – recall from the lecture that forward dynamics is useful for simulation and inverse dynamics is useful for control).
g. Repeat this at multiple instances of time along the trajectory and plot the error in position as a function of time.
h. Change the mass in your control law to an imprecise value like 2.8 kg. Observe the evolution of error over time.
i. Can you extend the controller to all the joints?"

## Conventions used
- Lecture notation: Q (or τ for one joint, F/𝓕 for Cartesian) for generalised actuation; q joint vector; x Cartesian; subscript d = desired; E = desired − actual (E = q_d − q, x_d − x, f_d − f_e); acute accent (f′, Q′, τ′) = commanded "acceleration-level" input to the servo; hats = estimates; bold = vectors/matrices. K_p position gain, K_v velocity gain. Dynamics form Q = M q̈ + C(q,q̇) + g + f(friction) as in Week 8.
- Gravity/angle sign: single-link q measured from the horizontal, mgL cos q term (p. 12).
- 𝒦 = forward kinematics map (calligraphic K); J = Jacobian; Jᵀ maps Cartesian force to joint torque.
- Lecturer's convention for force-control sign: f = mẍ + f_disturb + f_e (applied force balances inertia, disturbance and environment reaction; wall pushes back).
- Hybrid control figure follows Craig (ch. 10–11 recommended; also Lynch & Park ch. 11, p. 48). No DH conventions used in this deck.
