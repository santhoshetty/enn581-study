### What is inverse kinematics?

In the previous lesson, we saw how the forward kinematics mapping tells us about the pose of the robot's end effector, when the joint coordinates are known. Inverse kinematics is the opposite problem: what should the joint coordinates be, if we desire a certain pose for the end effector?

<!-- cell 4 md -->
Let $\textbf{q} = \begin{Bmatrix} q_1 & q_2 & \ldots & q_n \end{Bmatrix}^\top$ be a column vector representing the joint coordinates of a manipulator with $n$ joints.  
Let $\xi_n$ be the pose of the end effector with respect to the base frame of the robot. As mentioned in the previous lesson, $\xi_n$ can be given in terms of the homogenous transformation matrix, twist vector, quaternions or in any other form. 
Inverse kinematics can be thought of as a mapping from the end effector pose to the joint coordinates, i.e. $\textbf{q} =$ 𝒦$^{-1}(\xi_n)$.  

<!-- cell 5 md -->
---

<!-- cell 6 md -->
There are many key questions to consider when solving the inverse kinematics problem. We will consider them next.

<!-- cell 7 md -->
### Does a solution exist?  

Recall our discussion on the workspace of the manipulator from the first module. For a solution to exist, the chosen pose must lie in the workspace of the manipulator.

### Which solution should one choose?
If more than one solution exists, then there arises the question of which solution to use. Often, the answer to this question depends on the context. One criterion to use could be a measure of closeness, i.e. choose the solution that is closer in some defined way to the existing configuration of the robot. The absolute change in joint angles, weighted change in joint angles, the number of joints to move, the type of joints being moved are all possible measures of closeness. Sometimes, only one of the possible IK soultions might be admissible, for example, when an obstacle voids a solution. All these will have to be considered when choosing one of the many solutions.

<!-- cell 11 md -->
### How is the IK problem solved?

Broadly, there are two approaches. The first approach aims to obtain closed-form analytical expressions, relying on algebraic or geometric relations present in the mechanism. The second approach is to use iterative numerical techniques. We will discuss both.

<!-- cell 12 md -->
---

<!-- cell 13 md -->
### Analytic approach to IK

The general steps in the analytical approach can be summarised as
1. Create a model of the robot’s links and joints
2. Express forward kinematics Mathematically
3. Using geometric or algebraic relations, attempt to solve for joint parameters

This method explicitly shows all the solutions to the IK problem. Solutions are compact and fast to execute.


<!-- cell 14 md -->
### Example 1: Planar RR manipulator
Consider the planar RR manipulator shown below. The lengths of the links are $\mathrm{L_1}$ and $\mathrm{L_2}$. The inverse kinematics problem is to determine the joint coordinates $\mathrm{q_1}$ and $\mathrm{q_2}$, given the end effector pose $\mathrm{(x,y)}$.
<center>
    <figure>
        <img src="3_Figures\planar_RR.png"
            width="20%">
    </figure>
</center>

<!-- cell 15 md -->
We first write down the forward kinematics of this manipulator.

\begin{align*}
x &= \mathrm{L_1 \cos(q_1) + L_2 \cos(q_1 + q_2)} \\
y &= \mathrm{L_1 \sin(q_1) + L_2 \sin(q_1 + q_2)} \\
\end{align*}

Let us solve for joint angle $\mathrm{q_2}$. Squaring and adding gives

\begin{align*}
x^2 + y^2 = \mathrm{L_1^2 + L_2^2 + 2 L_1 L_2 \cos(q_2)}
\end{align*}

From this we get

\begin{align*}
\cos(\mathrm{q_2}) &= \frac{x^2 + y^2 - \mathrm{L_1^2 - L_2^2}}{2\mathrm{L_1 L_2}} \\
\sin(\mathrm{q_2}) &= \pm\sqrt{1 - \cos^2(\mathrm{q_2})}
\end{align*}

There are two solutions for $\mathrm{q_2}$, based on the sign of the sine.

<!-- cell 16 md -->
Now solve for the other joint angle $\mathrm{q_1}$. Use compound angle formulae in the forward kinematics equations.

\begin{align*}
x &= \mathrm{(L_1 + L_2 \cos(q_2))\cos(q_1) - (L_2 \sin(q_2))\sin(q_1)} \\
y &= \mathrm{(L_2 \sin(q_2))\cos(q_1) + (L_1 + L_2 \cos(q_2))\sin(q_1)} \\
\end{align*}


<!-- cell 17 md -->
The general solution for an equation of the type $A\cos(\phi)+B\sin(\phi) = C$ is

\begin{align*}
\phi = \tan^{-1}\left(\frac{C}{\pm\sqrt{A^2+B^2-C^2}}\right) - \tan^{-1}\left({\frac{A}{B}}\right)
\end{align*}

<!-- cell 18 md -->
Using this, we obtain

\begin{align*}
\mathrm{q_1} = \tan^{-1}\left(\frac{y}{x}\right) - \tan^{-1}\left({\frac{\mathrm{L_2 \sin(q_2)}}{\mathrm{L_1 + L_2 \cos(q_2)}}}\right)
\end{align*}

<!-- cell 19 md -->
Using the two solutions for $\mathrm{q_2}$, we get two solutions for $\mathrm{q_1}$. It is intuitive that there would be two solutions and these correspond to the so-called 'elbow up' and 'elbow down' configurations of the manipulator.

### Numerical approach to IK

The general idea behind the numerical approach can be summarised as follows.  
We can always determine the forward kinematics of a robot, $\xi =$ 𝒦$(\textbf{q})$.  
Say we want to solve the IK problem for a desired goal pose $\xi^*$.  
Start with an initial set of joint coordinates $\textbf{q}$ and a corresponding pose $\xi$.  
Adjust the joint coordinates $\textbf{q}$ until $\xi \rightarrow \xi^*$.  
The resulting set of joint coordinates $\textbf{q}^*$ is a solution to the IK problem.

In other words, we are solving an optimisation problem.

$\textbf{q}^* = \arg \min \limits_{\textbf{q}} \lvert$ 𝒦 $(\textbf{q}) \ominus \xi^* \rvert$

Here $ G(\textbf{q}) := \lvert$ 𝒦 $(\textbf{q}) \ominus \xi^* \rvert$ is called the goal potential that we seek to minimise. There are many ways to define the goal potential. Eucledian distance is a simple example if orientation is ignored.

### Using the Robotics Toolbox to solve the IK problem numerically

<!-- cell 31 md -->
Let us revisit the Furuta Pendulum from the previous lesson and try to solve the IK problem for it.

<!-- cell 32 code -->
```python
# define the Furuta pendulum model
E1 = rtb.ET.tz(0.50)
E2 = rtb.ET.Rz()
E3 = rtb.ET.tx(0.40)
E4 = rtb.ET.Rx()
E5 = rtb.ET.tz(-30)
E6 = rtb.ET.Ry(np.pi)

ets_furuta = E1 * E2 * E3 * E4 * E5 * E6
print("ETS for the Furuta Pendulum", ets_furuta)

# we can use the ETS to create a robot object
robot_furuta = rtb.Robot(ets_furuta)
print(robot_furuta)

# to test the IK solution, let us first create a known pose using FK
q_test = np.array([np.pi/3, np.pi/6])

# the tool end pose is obtained by running the fkine method on the ETS object
xi = ets_furuta.fkine(q_test)

# to commpute the IK solution, we can use the ikine method on the robot object
# Here we are using the python based Levenberg-Marquardt solver
# For a list of available solvers, see https://petercorke.github.io/robotics-toolbox-python/IK/ik.html
IK_solution = robot_furuta.ikine_LM(xi)

# let us now verify if the IK solution is correct
print("IK solution for joint coordinates:", IK_solution.q)
print("test joint coordinates:", q_test)
```

### Numerical vs. Analytical approach

Closed-form analytical solutions are potentially faster than an iterative numerical solution. The benefit of a closed-form solution is that a solution to all possible manipulator positions can be determined *a priori*. However, as the number of joints increases, finding a closed-form solution becomes challenging. Numerical methods are more suited to large kinematic chains. They can help arrive at a close-enough solution when an exact solution does not exist.
