\hd*{Answer layout (method marks)}
\begin{enumerate}
\item \textbf{Draw and define}: frames, axes, positive angle directions, assumptions (no joint limits; point masses; rest to rest; $\gamma=0$).
\item \textbf{State the general tool} before using it: ETS, cosine rule, Euler–Lagrange, G–K, boundary conditions.
\item \textbf{Substitute and simplify}, one step per line, symbols first, numbers last, with units.
\item \textbf{Box the result}; list \emph{every} branch (IK) or mode (four-bar).
\item \textbf{Sanity check} at $\theta=0$, $t=0$, or a symmetric case. Write ``check:''.
\end{enumerate}
\hd*{Time (2 hours)}
Read all questions first (5 min). Split time by marks. Leave 10 min to check signs and units. If stuck: write the set-up and the equation you would solve, then move on.

\hd*{Ten checks before you hand in}
\begin{enumerate}
\item Calculator in \textbf{radians}? Angles labelled ° or rad?
\item atan2, not $\tan^{-1}(y/x)$ (quadrant).
\item Both IK branches (and ``no solution if $|\cos|>1$'').
\item Order of matrix products (right = about the current frame).
\item Transposes: $\Rm^{-1}=\Rm^\top$; inverse $\T^{-1}=[\Rm^\top\ \ -\Rm^\top\mathbf t]$.
\item $\mathcal L=K-P$; gravity sign; product rule in $\frac{d}{dt}$.
\item $k_v^2=4k_p$ for critical damping (unit mass).
\item Ground counted as a link; $D=3$ planar, 6 spatial.
\item Wheel row: $-\dot\theta\,{}^Cy$ in the $x$ part, $+\dot\theta\,{}^Cx$ in the $y$ part.
\item Units: mm vs m; rad/s vs rpm; N\,m vs N.
\end{enumerate}
